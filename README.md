# LATINOS BOOKING — prototipo visual

Este paquete contiene una primera interfaz adaptable a móvil basada en el logo oficial:
- negro como fondo principal
- plata/blanco en la tipografía
- acentos cian y rojo tomados del efecto cromático del logo
- partículas, órbitas y barrido de luz con movimiento sutil

## Probar localmente
Abre `index.html` en un navegador.

## Publicar en GitHub + Vercel
1. Crea un repositorio en GitHub llamado `latinos-booking`.
2. Sube `index.html` y la carpeta `assets`.
3. En Vercel, importa ese repositorio.
4. Para este prototipo estático no hacen falta variables de entorno.

## Importante
La selección de barbero, servicios, fecha y hora es interactiva, pero los horarios son demostrativos. Este prototipo todavía NO consulta Supabase ni crea reservas. La conexión real se implementará después con la URL del proyecto y la clave publishable, manteniendo cualquier clave secreta exclusivamente en servidor.
